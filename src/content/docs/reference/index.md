The released specification set for NXS: the **Interface Description**
(registers, commands, wire formats, procedures — the normative contract),
the **Integration & Operation Manual**, the **Driver Development Guide**,
and the co-processor **Datasheet**.

Every SDK release bundle carries the complete set, and this section
mirrors it release by release — the documents here always match the
firmware a release ships.
