For the first person who opens the box. Each guide is one hardware set
and one path through it: every command, and the output it prints, in
order. Nothing here explains what the Reference section explains; a
guide stops where a specification begins.

The set is numbered. **1. Unboxing**: one NXS unit on an NXS Hub, then
the same commands over CAN and serial. **2. Custom sensor**: a patch
generated from a datasheet, run beside a shipped one, changed in Python,
calibrated, and configured through an agent. **3. Dual camera**: two
cameras on one Hub with a unit riding link A. A SLAM rig guide is
reserved as number 4.

These pages are mirrored from the firmware repository at every release;
fixes go to its `docs/guides/` and arrive with the next release.
